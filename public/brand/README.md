# Checkout branding

`mind-checkout-icon.png` is a 512 × 512 transparent PNG rendered from the existing vector mark in `components/ui/logo.tsx`, using its original paths and the Mind foreground color `#17181a`. The viewBox is cropped to `240 220 550 550` for legibility in Stripe's small brand header. No new logo or external artwork is introduced.

The hosted checkout uses this asset with the display name Mind, Inter (Stripe-supported), rounded controls, `#fafafa` background and `#17181a` primary button. Appearance is scoped to Checkout Sessions; it does not change the landing or global Stripe account settings.
